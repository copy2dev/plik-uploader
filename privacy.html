Privacy Policy for Plik Uploader

Last updated: 9 November 2026

Plik Uploader is a private tool used only by the owner of the YouTube channel "Plik" (@plikstory) to upload and schedule videos to that channel through the YouTube API Services.

Data accessed

When the owner signs in with Google, the tool receives an OAuth token that allows it to upload videos, set thumbnails, upload captions and add videos to playlists on the owner's own channel. It reads only the owner's channel name and ID to confirm the upload target.

Data storage

The OAuth token and upload records are stored only on the owner's own computer. Nothing is sent to any server other than Google's.

Data sharing

No data is sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Contact the owner through the YouTube channel @plikstory.
